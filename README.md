# Природні Мандри — frontend

Next.js застосунок RelaxMap. Браузер ходить лише в `app/api`, далі запит проксується на бекенд.

## Запуск

```bash
npm install
cp .env.template .env
npm run dev
```

Бекенд має слухати `http://localhost:4000`. Сайт: `http://localhost:3000`.

Розклад задач і проміжний дедлайн: `../TASKS.md`.
